# Course Overview
This course discusses the following topics of C++ programming:

* Type and Struct
* Uniform Initialization
* Reference
* Streams
* Containers
* Iterators
* Function Templates
* Lambda Function
* Template Class
* Const-Correctness
* Operator Overloading
* Special Member Function
* Move Semantics
* Resource Acquisition Is Initialization(RAII)

The course slides are from cs106L win2020.
